# 保卫萝卜 · 复刻版

一个可以直接在浏览器里玩的塔防游戏，复刻《保卫萝卜》的核心玩法：沿路埋炮塔、拦住一波波兔子、保住那颗胡萝卜。
后端是 Python 标准库写的本地服务器（负责托管页面 + 存玩家存档），前端是原生 HTML/CSS/Canvas，零依赖、零联网。

## 可移植启动器（C++）

`launcher/launcher.cpp` 是一个零第三方依赖的 C++17 启动器，编译后是单个 exe：

```bash
cd launcher && bash build.sh
```

它的工作流程：

1. 先找随包携带的便携版 Python（`runtime/python`），再找系统 Python；
2. 都没有就自动补齐：对华为云、清华 TUNA、阿里云、npmmirror、python.org 五个源**实测延迟并排序**，选最快的下载，失败自动切下一个；
3. 下载后校验大小、解压、验证 Python 能运行；
4. 检查端口占用（自动顺延），启动 `server.py`。

## 怎么跑

**双击 `start.bat` 就行**（Windows）。浏览器会自动打开游戏，关掉那个黑窗口就停止游戏。

启动器会自动找到可用的 Python，端口被占用时会自动顺延到下一个（会打印实际地址）。没装 Python 的话它会给出下载地址和提示，不会一闪而过。

macOS / Linux 用 `./start.sh`。

也可以命令行手动启动：

```bash
python server.py                 # 默认 8000，占用时自动顺延
python server.py --port 8123     # 指定端口
python server.py --no-open       # 不自动打开浏览器
python server.py --strict-port   # 端口被占用就直接报错，不顺延
```

## 怎么玩

主菜单进「开始游戏」直接进当前最新解锁的关卡，或者走「关卡选择」挨个打。

- **建塔**：开局就在建造模式，整片草地都亮着「+」标记，点哪格就在哪格起塔，**可以连着点一串格子连续建造**。想换塔就点下方商店卡片，想退出建造就右键或按 Esc。
- **升级 / 拆除**：点场上的塔，面板会**贴在那座塔旁边**弹出，可以升级（最高 3 级）或按 7 折拆掉换回金币。
- **建筑（多格障碍）**：石头、蘑菇、木箱、水晶、树、房子、栅栏、废墟散布在地图上，**有的占好几格**。它们头顶有**常驻血条**，血量和怪物一样，**只能靠炮塔打掉**，没有花钱拆除这种捷径。
- **锁定目标**：**点一下怪物或建筑就锁定**（准星会转起来，射程内的炮塔会各自连一条虚线过去），再点同一个目标取消。锁定后炮塔优先打它——但只有**在它射程内**的炮塔会响应，够不着的照常打自己范围里的怪。没锁定时炮塔**不会主动去打建筑**，只有锁定建筑才会集中拆。
- **道具（金币购买）**：底部道具栏是商店，炸弹 120 / 冰冻 90 / 闪电 150，点一下就买进背包；买了再点一次进入投放模式，点地图任意位置释放。
- **打怪掉钱**：击杀时飘出「+N」金币数字，打碎建筑也会掉金币。
- **血条**：HUD 上萝卜有数值和血条，血量越低越红并闪烁；被漏过会扣血并抖动。
- **波次**：每波前有倒计时，HUD 显示当前波次、本波剩余、以及**下一波会来什么怪**。
- **最终 Boss**：第 8 关最后一波先来一大波小怪，16 秒后**暗影龙王**压轴登场（血量 3 万起，配合波次成长实际约 4.7 万），带专属血条与登场警告。
- **结算**：全波清空即通关，按萝卜剩余血量给 1–3 星；萝卜血被啃光**真的会失败**。结算面板会显示获得金币、用时、击杀数与打到的波次。

快捷键：`空格` 或 `Esc` 暂停/继续，`1` 快速选中第一种炮塔，右键取消建塔模式。

## 内容

**12 种炮塔**，每种有独立的攻击策略：

| 炮塔 | 打法 | 特点 |
|---|---|---|
| 瓶子塔 | 单体 | 便宜均衡，开局主力 |
| 弓箭塔 | 穿透 | 射程最远，能穿过多只 |
| 风扇塔 | 扇形多弹 | 一次撒出多枚风刃 |
| 冰冻塔 | 溅射减速 | 拖住整条流水线 |
| 火炮塔 | 溅射 | 高伤范围，专治成串 |
| 魔法塔 | 大范围溅射 | 爆炸半径最大 |
| 闪电塔 | 连锁 | 电流在敌人间跳跃 |
| 太阳花塔 | 持续光束 | 单体秒伤最高 |
| 毒菇塔 | 中毒 | 命中后持续掉血 |
| 狙击塔 | 暴击 | 概率打出双倍伤害 |
| 导弹塔 | 追踪 | 锁定目标必中 |
| 战鼓塔 | 光环 | 不攻击，给周围友军加攻 |

**12 种兔子 + 3 个 Boss**：呆萌兔、疾风兔、铁甲兔、蹦蹦兔、药师兔（治疗同伴）、盾甲兔（有护盾）、飞行兔、分裂兔（死后裂成小兔）、幽灵兔（半透明）、狂暴兔（越掉血越快）、重装兔（高护甲）、迷你兔；Boss 是萝卜王、兔王、**暗影龙王**（最终 Boss）。

8 个关卡，主题覆盖森林、沙漠、冰雪、糖果、熔岩、天空，难度递增，后两关是双路径夹击；第 8 关以暗影龙王收尾。

## 文件结构

```
pwlb/
  start.bat              Windows 一键启动（双击即可）
  start.sh               macOS / Linux 一键启动
  server.py              后端：静态托管 + 存档 API（只用标准库）
  web/
    index.html           单页：主菜单 / 选关 / 图鉴 / 战斗 / 三个弹窗
    css/                 base / ui / hud 三层样式，纯 CSS 画的卡通风背景
    js/engine.js         内核：路径、敌人、炮塔、弹丸、波次
    js/render.js         渲染：地砖烘焙、路径、塔、敌人、特效
    js/sprites.js        美术：全部程序化 Canvas 绘制，无图片资源
    js/audio.js          音效：WebAudio 实时合成，无音频文件
    js/main.js           主控：屏幕切换、输入、HUD、存档
    data/                towers.json / enemies.json / levels.json
  scripts/gen_levels.py  关卡数据生成器（塔位自动布局并校验不压路）
  tests/test_api.py      后端接口单元测试
  tests/validate_data.py 关卡数据合法性校验
  saves/                 运行后生成：玩家档案与成绩
```

## 改数值 / 加关卡

炮塔与敌人数值都在 `web/data/towers.json`、`enemies.json` 里，改完刷新页面即生效。
关卡从 `scripts/gen_levels.py` 里的 `LEVELS` 定义生成，改完执行：

```bash
python scripts/gen_levels.py web/data/levels.json
python tests/validate_data.py
```

生成器会自动挑出「贴着路、不压路、彼此不扎堆」的塔位；路径如果不是横平竖直会直接报错。


## 存档

玩家档案存在 `saves/profile.json`（金币、星级、解锁进度、音量设置），成绩追加到 `saves/scores.json`，排行榜接口 `GET /api/leaderboard`。删掉 `saves/` 目录即可重置进度。
